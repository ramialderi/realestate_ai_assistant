# بوت تليجرام - مساعد عقاري

بوت جاهز للعمل، مبني بلغة Python، يسمح لوكلاء العقارات بإضافة عقاراتهم، وللزوار بتصفح العقارات والبحث فيها حسب النوع، المدينة، والسعر. قاعدة البيانات محلية (SQLite) بدون أي تكلفة.

## المزايا
- قائمة تفاعلية بأزرار (تصفح / بحث متقدم / إضافة عقار / عقاراتي / تواصل)
- **🤖 مساعد ذكي**: الزائر يكتب سؤاله بلغة طبيعية ("بدي شقة بدمشق أقل من 500 دولار") والبوت يفهمه ويرد بعقارات فعلية من القاعدة
- تصفية حسب: نوع العملية (بيع/إيجار)، نوع العقار، المدينة، نطاق السعر
- كل وكيل يضيف ويحذف عقاراته فقط
- دعم الصور داخل الإعلان

## 1) إنشاء البوت (مجاناً بالكامل)
1. افتح تليجرام وابحث عن **@BotFather**.
2. أرسل الأمر `/newbot` واتبع التعليمات لاختيار اسم ومعرف (username) للبوت.
3. سيعطيك BotFather **توكن** (Token) — احتفظ فيه سرياً.

## 2) تفعيل المساعد الذكي (مجاني)
1. افتح https://console.groq.com/keys وأنشئ حساب مجاني.
2. أنشئ مفتاح API جديد (يوجد حد استخدام يومي مجاني سخي، يكفي لبوت متوسط النشاط).
3. احتفظ بالمفتاح لاستخدامه كمتغير بيئة `GROQ_API_KEY`.

كيف يعمل: عندما يكتب الزائر سؤالاً حراً (مو من الأزرار)، يقوم البوت أولاً بفهم طلبه (نوع العملية، المدينة، الميزانية...)، يبحث في قاعدة البيانات الفعلية عن العقارات المطابقة، ثم يصيغ رداً طبيعياً بالاعتماد فقط على تلك النتائج (بدون اختلاق معلومات). إن لم يضبط `GROQ_API_KEY` سيخبر البوت الزائر أن الميزة غير مفعّلة بعد بدل أن يتعطل.

## 3) التشغيل محلياً
```bash
pip install -r requirements.txt
export BOT_TOKEN="التوكن_من_BotFather"       # على ويندوز: set BOT_TOKEN=...
export GROQ_API_KEY="مفتاح_Groq"             # على ويندوز: set GROQ_API_KEY=...
python bot.py
```
البوت سيعمل بنظام polling (لا يحتاج سيرفر أو دومين).

## 4) رفعه مجاناً للتجربة (GitHub + Render) — نسخة العرض على الزبون
هذا هو الوضع المناسب الآن: نسخة تجريبية يجربها الزبون مجاناً قبل الشراء. البوت مبرمج بحيث يعمل **محلياً بنظام polling**، وتلقائياً **بنظام webhook** بمجرد رفعه على Render (بدون أي تعديل يدوي).

### أ) رفع الكود على GitHub
1. أنشئ مستودع (repo) جديد فارغ على GitHub.
2. ارفع كل ملفات المشروع (`bot.py`, `database.py`, `ai_assistant.py`, `requirements.txt`, `render.yaml`) إليه.

### ب) النشر على Render (خطة Free)
1. سجّل دخول على https://render.com بحساب GitHub.
2. اضغط **New +** → **Blueprint**، واختر المستودع اللي رفعته — Render سيكتشف ملف `render.yaml` تلقائياً ويجهز خدمة ويب مجانية.
   - (بديل يدوي: **New +** → **Web Service**، اختر المستودع، Environment: Python 3، Build Command: `pip install -r requirements.txt`، Start Command: `python bot.py`، Plan: **Free**)
3. أضف متغيرات البيئة من تبويب Environment:
   - `BOT_TOKEN` = التوكن من BotFather
   - `GROQ_API_KEY` = مفتاح Groq
4. اضغط Deploy. بعد اكتمال النشر، سيعطيك Render رابطاً مثل `https://your-bot.onrender.com` — لا داعي لفعل أي شيء يدوي به، البوت نفسه يسجّل الـ webhook تلقائياً عند الإقلاع لأن Render يوفر متغير `RENDER_EXTERNAL_URL` تلقائياً.

### ج) ملاحظة مهمة عن الخطة المجانية
خدمة الويب المجانية على Render "تنام" بعد 15 دقيقة بدون أي طلب، وأول رسالة توصل بعدها بتتأخر حوالي 30-60 ثانية لحين استيقاظها (المرات اللي بعدها بترد فوراً). لتفادي هذا التأخير أثناء عرضك على الزبون:
- استخدم خدمة **UptimeRobot** (مجانية): أنشئ حساب على https://uptimerobot.com، وأضف Monitor من نوع HTTP(s) يفحص رابط `https://your-bot.onrender.com` كل 5 دقائق — هذا يبقي الخدمة مستيقظة طول الوقت.

## 5) إذا انباع: الترقية لاستضافة مضمونة (Background Worker مدفوع)
الخطة المجانية ممتازة للعرض التجريبي، لكن غير موثوقة لعميل حقيقي يعتمد عليها يومياً (تأخير النوم/الاستيقاظ، وموارد محدودة). عند البيع:
1. على Render: غيّر نوع الخدمة إلى **Background Worker** (حوالي 7$/شهرياً)، وأمر التشغيل نفسه `python bot.py` — بما إنه لا يوجد `RENDER_EXTERNAL_URL` لهذا النوع، البوت سيعمل تلقائياً بنظام **polling** المستقر بدون أي تعديل بالكود.
2. أو استخدم Railway.app بخطة مدفوعة رخيصة (~5$/شهرياً) بنفس الطريقة.
3. لكل عميل جديد: أنشئ بوت تليجرام منفصل بتوكن خاص (خطوة 1)، وكرر نفس عملية النشر.

## 6) فكرة البيع كخدمة (White-label)
بما أنك تنوي بيعه كمساعد عقاري:
- لكل عميل (مكتب عقاري) أنشئ **بوت تليجرام منفصل** عبر BotFather (توكن مختلف)، وشغّل نسخة منفصلة من نفس الكود له — بذلك يظهر البوت باسمه الخاص.
- يمكنك تخصيص الاسم والشعار (Bot Picture, About) من BotFather لكل عميل.
- كل عميل يحتاج مفتاح `GROQ_API_KEY` خاص به (أو يمكن مشاركة نفس المفتاح بين عدة بوتات إن كان حد الاستخدام المجاني كافياً).
- يمكن لاحقاً إضافة: اشتراك شهري، لوحة تحكم ويب، أو ترقية المساعد الذكي إلى نموذج أقوى (مثل Claude API) عند الحاجة لدقة أعلى.

- `/cancel` — إلغاء أي عملية جارية (إضافة عقار أو بحث)
